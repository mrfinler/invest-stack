Research date: 2026-10-13. Web sources only; paraphrased. "Date" = publish / last-updated date shown on the page.
Caveats up front: several review sites are affiliate or sponsored (flagged). Pantip and Reddit threads could not be fetched directly; Reddit evidence comes via an aggregator (GummySearch). No Thai-language user forum thread about multi-asset trackers was found and read. **Treat the Thai-specific user voice as thin.**

## 2. Minimal manual data and assets without a price feed
- Typical manual minimum = **ticker + quantity + average cost/cost basis** (Simply Wall St manual entry: tickers, shares, average purchase price; Stock Events: price + date). Sources above.
- Kubera: if you don't link accounts, add stocks/crypto by ticker; anything else is a value in a spreadsheet row, entered in its own currency (e.g. "EUR 100"); history kept per update. (upd. 2025-11-08) https://help.kubera.com/article/17-dont-want-connecting-bank-accounts
- **Check-in pattern (Kubera "Mark as Stale")**: manual rows flagged stale on a schedule (weekly/monthly/yearly) with email reminder; default monthly on the first sheet. (upd. 2026-07-26) https://help.kubera.com/article/46-what-is-mark-as-stale
- Kubera "Cruise Control": set an interest rate on a manual deposit/loan and value auto-grows monthly/quarterly/yearly; override any time. (upd. 2025-12-18) https://help.kubera.com/article/157-cruise-control
- Sharesight custom investments: user must enter prices manually (or CSV bulk upload); merge into listed security later. (upd. 2026-09-22) https://help.sharesight.com/unquoted-instruments
- Empower: manual balance when a link fails (Get Rich Slowly, above).
- Users' stated requests for the *minimum dashboard*: total invested vs current value (Jitta review 2021), returns against total deposits (Trading 212 forum 2024-12-27).
- **Not verified:** no source quantifies how many fields users tolerate; "quantity + net invested + current value/profit" as a minimum is a reasonable inference from the above, not a measured finding.

## 3. Feature demand (approximate ranking)
No survey ranks these; ranking below is my judgement from how often each appears in reviews/requests read here. Treat as indicative.

1. **Net worth / one view across accounts and asset classes** – Reddit aggregator top theme; Trading 212 "combined home screen" request (2024-12); Stock Events/Snowball praise; SET's wiset rationale (2026-06). https://community.trading212.com/t/2025-most-wanted-features/79778
2. **Multi-portfolio / sub-portfolios** – Trading 212 requests (2024-12-26/28); Dime user (2023-04-08); Snowball tiering.
3. **Dividend tracking/calendar/forecast** – most praised feature in Snowball and Stock Events reviews (2026); Dime added Dividend Analytics.
4. **Return vs money actually put in / correct return method** – Trading 212 (TWR request; return vs deposits), Jitta (invested vs value). Sharesight uses money-weighted, calls TWR potentially misleading for individuals (2025-09-17) https://www.sharesight.com/blog/time-weighted-vs-money-weighted-rates-of-return ; Canadian Couch Potato argues TWR for benchmark comparison (2015-07-20) https://canadiancouchpotato.com/2015/07/20/how-contributions-affect-your-rate-of-return/ ; Wealthfront: simple return misleads, show both TWR and MWR (2021-06-21) https://www.wealthfront.com/blog/whats-your-investment-return/ . Best practice: show both, labelled.
5. **Currency effect for foreign assets** – Dime FX complaint (2023); Sharesight and Simply Wall St split currency gain; Yahoo ignores currency effect (Finxter 2025-04-30); Reddit complaint of messed-up currencies.
6. **Benchmark comparison** – Sharesight, Kubera, Snowball, Portseido, getquin all offer; requested less often by users than shown by vendors.
7. **Allocation vs target / rebalancing** – Snowball targets; Empower allocation; StockRover survey (2015) put rebalancing mid-tier. https://ww1.stockrover.com/blog/user-survey-results/
8. **Contribution/DCA tracking** – Finnomena DCA plans; Trading 212 "returns vs deposits". Rarely a standalone request; usually expressed as #4.
9. **News/events per holding** – Stock Events timeline is praised; Dime groups stock news with assets. Moderate.
10. **AI summaries** – now marketed by getquin and Snowball; one Snowball reviewer praised it (2026-09-08). Little organic user demand found; **unverified as a top want**.

## 4. Pain points to avoid
- **Manual-entry friction / broken sync**: Sharesight, Delta, Empower, Stock Events all draw this. Fewest required fields, CSV/screenshot import, and scheduled check-ins reduce it.
- **Misleading numbers**: wrong dividend projections and cash totals (Snowball 2026); P/L ignoring FX (Dime 2023); simple return distorted by deposits (Wealthfront). Label method, split FX vs price.
- **Clutter / upsell**: Investing.com/Yahoo cluttered with ads, getquin social feed confusing, Empower sales calls (Finxter 2025; GRS 2025). Nagging notifications (Delta 2025).
- **Pricing traps**: holding caps counting sold positions (Sharesight 2025), surprise trial charges (Delta 2025), auto-renewal (Simply Wall St 2026).
- **Privacy**: reluctance to hand credentials to aggregators like Plaid (DepositAccounts thread, 2022-07/08) https://www.depositaccounts.com/community/ask/48462-plaid-privacy-security-concerns.html ; preference for local/open-source tools (Ghostfolio, Rotki, PortfolioTracker24) and read-only/CSV-only import (Portseido).
- **Reliability**: crashes and outages are the top Delta complaint (2025).
