# Attack the Thesis

- **Find the shared premise.** When several reasons for a call all hold only if one thing stays true (rates fall, AI spending keeps growing, the baht stays weak), you have one reason, not several. Name it and check it on its own.
- **Write the kill condition.** Every recommendation ends with "เปลี่ยนใจถ้า…", a specific observable event with a number or a date. "If sentiment turns" does not count.
- **Steelman the other side.** Before recommending, write the strongest case against it in the form its best advocate would use. If you cannot, you do not understand the call yet.
- **Watch for momentum disguised as analysis.** "It went up so it is good" and "it went down so it is cheap" are both price talking. Ask what changed in the business.
- **Owned is not evidence.** Ped owning a stock is not a reason to keep it. Ask the cash question: if he held this money in cash today, would he buy this at this weight?
