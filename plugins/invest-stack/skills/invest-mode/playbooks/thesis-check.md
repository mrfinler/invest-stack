# Thesis check

"Should I still hold X?" The test is whether the reason Ped bought it still holds, not whether the price went up.

## Steps

1. **Find the thesis.** Read the `note` on every buy of the ticker in the ledger, and what past briefs said about it (`bigdata_search` with context "search in my private files", tag `ped-weekly`). If there is no note, ask Ped for the reason in one line and wait.
2. **Turn it into checks.** Each reason becomes one or two observable facts with a source ("cloud revenue growing faster than 25% a year" becomes the last two quarters' segment numbers from the 10-Q).
3. **Check each one** against primary sources. Mark holds, weakening, or broken, with the source.
4. **Attack it.** **principle-attack-the-thesis**: if the reasons share one premise (for example "AI capex keeps rising"), check that premise directly.
5. **Debate.** **bull-bear-arena** on "keep, add, or trim".
6. **Reply and store.** Thai, per **unslop-th**. Store as `analyses` kind `deep`, linking the checks.
